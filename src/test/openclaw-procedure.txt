Use Code Mode, se disponivel, para manter os passos 1-4 em UM programa, sem round-trips do modelo durante a janela ativa. OBRIGATORIO: a celula externa Code Mode deve usar awaitResults:false (ou omitir), e toda chamada interna de exec para um Runner deve usar awaitResults:false explicitamente. NUNCA use awaitResults:true nessa demonstracao: celulas required propagam a espera ate o termino do shell e ignoram o objetivo de yieldMs, impedindo acompanhar/cancelar. O exec externo pode retornar waiting com runId de CELULA; retome-o com wait, nao confunda esse ID com sessionId de PROCESSO ou runId do Runner.
